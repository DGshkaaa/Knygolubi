# Листи підтвердження на Render Free

Render Free блокує вихідний SMTP на портах 25, 465 і 587. Пароль додатку Google може працювати локально, але не усуває це обмеження на сервері.

Підтримується надсилання через Brevo HTTPS API на порту 443. За наявності `BREVO_API_KEY` застосунок використовує API; без нього — наявний SMTP.

## Безкоштовне підключення

1. Створіть безкоштовний акаунт на https://app.brevo.com/ та підтвердіть його. Free має ліміт 300 листів на день; не обирайте платний тариф.
2. Додайте і підтвердіть адресу відправника в налаштуваннях **Senders, Domains & Dedicated IPs → Senders**. Для Gmail Brevo може замінювати видиму адресу на власну сумісну адресу доставки. Переконайтеся, що transactional email увімкнено; якщо Brevo просить перевірити акаунт, завершіть перевірку.
3. У **SMTP & API → API Keys** створіть API-ключ. Це ключ Brevo API, а не SMTP-ключ і не пароль додатку Google. Збережіть його лише в Render Environment, не в Git і не в чаті.
4. Для бекенду **Knygolubi** на Render додайте:

   ```dotenv
   BREVO_API_KEY=<ключ Brevo API>
   EMAIL_FROM_EMAIL=<підтверджена адреса відправника>
   EMAIL_FROM_NAME=Книголюби
   FRONTEND_URL=https://knygolubi-1.onrender.com
   ```

5. Розгорніть коміт із підтримкою Brevo та застосуйте змінні Environment.
6. Для вже створеного непідтвердженого профілю натисніть **Надіслати лист ще раз**. Повторно створювати чи видаляти профіль не потрібно.
7. Перевірте лист у скриньці одержувача та в **Transactional → Logs** у Brevo. Прийняття API-запиту не гарантує доставку: можливі відмови адреси, спам-фільтри або вичерпання квоти.

До підключення реального API-ключа надсилання на Render Free через Gmail SMTP залишатиметься недоступним.

## Перевірки

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

Тести API не надсилають справжніх листів. Вони перевіряють HTTPS-запит, одержувача, посилання на публічний сайт, обробку відмов, тайм-аутів, неправильного ключа та відсутність переходу назад до заблокованого SMTP після помилки API.

Джерела: https://render.com/docs/free, https://developers.brevo.com/reference/send-transac-email, https://help.brevo.com/hc/en-us/articles/208589409-About-Brevo-s-pricing-plans
