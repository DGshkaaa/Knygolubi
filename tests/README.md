# Перевірки реєстрації та пошуку

Запуск із кореня проєкту (достатньо залежностей з `requirements.txt`):

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

Тести виконують HTTP-запити до FastAPI через ASGI з ізольованою колекцією в пам’яті. Жива MongoDB та зовнішній SMTP у тестах не використовуються.

Перевіряються реєстрація, хешування пароля і токена, підтвердження пошти та вхід, повторна адреса і конфлікт одночасної реєстрації, валідація, відсутність SMTP, збій надсилання та відновлення через повторний лист, прострочені й використані посилання, неправильні облікові дані, HTML і текстова версії листа, TLS/SSL, відмова одержувача та пошук зі спеціальними символами.

Перевірка фронтенду:

```powershell
cd frontend
npm run build
npm run lint
```

Для ручної перевірки відкрийте `/register`, `/login` та `/verify-email` на широкому й мобільному екранах у світлій і темних темах. У панелях персоналу перевірте пошук книг і користувачів, очищення пошуку та поля редагування.

Для реальної доставки потрібно налаштувати SMTP у `.env`. `FRONTEND_URL` визначає адресу посилання в листі: локально це `http://localhost:5173`, на сервері — публічна HTTPS-адреса фронтенду.

Локальна перевірка доставки підтвердила появу тестового листа у «Вхідних» Gmail. Такий окремий тест надсилання не створює акаунт; повний сценарій підтвердження перевіряється автоматичним тестом.
